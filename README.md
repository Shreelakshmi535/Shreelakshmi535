![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)

A production-grade SRE platform built on Red Hat OpenShift demonstrating the full reliability engineering lifecycle — deployment, monitoring, alerting, secret management, AI model serving, and incident response.

**What I built:**
- 🔐 Deployed Python Flask app on OpenShift with **RBAC, custom SCCs**, resource limits, liveness/readiness probes, and TLS-terminated Route
- 🔑 Configured **HashiCorp Vault Agent sidecar** using Kubernetes auth method — zero hardcoded credentials
- 📊 Instrumented app with **Prometheus metrics** (Counter, Histogram, Gauge) with ServiceMonitor CRD for auto-scraping
- 📈 Built **6-panel Grafana dashboard** — request rate, error rate, p50/p95/p99 latency, pod restarts, CPU, memory
- 🎯 Defined **3 SLOs** (99.9% availability, p99 < 2s, error rate < 0.1%) with PromQL and Alertmanager rules
- 🤖 Deployed scikit-learn model as **KServe InferenceService on RHOAI**
- 📝 Simulated OOMKill incident, triaged via Grafana, and authored a **full postmortem with RCA**

```
app/            ← Flask app with Prometheus metrics + non-root Dockerfile
openshift/      ← Deployment, Service, Route YAML manifests
monitoring/     ← Prometheus config, Grafana dashboard JSON, alert rules
```
